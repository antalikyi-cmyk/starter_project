# Прототип системи: Freight Cost Calculator

## 1. Опис рішення
Система — логістичний калькулятор собівартості перевезення для маршрутів Україна → Польща → Литва. Вона дозволяє:
- швидко обирати пункти пропуску, маршрути, точки завантаження/вивантаження та транспорт;
- отримувати розрахунок собівартості за 3 хвилини;
- змінювати ключові параметри без редагування формул;
- експортувати результати в Excel;
- адмініструвати довідкові дані та інтегруватися з реальними базами маршрутів.

## 2. Ключові бізнес-вимоги
- Автоматичний розрахунок собівартості залежно від обраного пункту пропуску, автомобіля та режиму рейсу.
- Підтримка української мови за замовчуванням.
- Доступність експорту результатів до Excel.
- Розрахунки з точністю до 0,01 валюти.
- Обробка змін не довше 1 секунди.
- Адміністративний модуль для управління маршрутами, транспортом, тарифами та довідковими даними.
- Інтеграція з реальними базами даних маршрутів та тарифів.

## 3. Архітектура екрану
### 3.1. Головний екран розрахунку
- Пункт пропуску Україна–Польща (drop-down)
- Місце завантаження в Литві (drop-down)
- Місце вивантаження в Литві (drop-down)
- Вибір автомобіля перевізника (drop-down)
- Режим рейсу: «на пусто» / «з вантажем» (drop-down)
- Вартість пального за одиницю
- Кнопка `Розрахувати`

### 3.2. Екран результату
- Загальна собівартість перевезення
- Розбивка витрат:
  - паливо
  - амортизація
  - експлуатаційні витрати
- Відстань маршруту
- Прогноз економії: зниження непередбачуваних витрат
- Кнопки `Експорт в Excel`, `Зберегти розрахунок`, `Новий розрахунок`

### 3.3. Адміністративний екран
- Довідкові дані маршрутів:
  - пункти пропуску
  - відстані
  - типи трас
- Дані автомобілів:
  - модель
  - витрати пального
  - амортизація
  - вантажна/порожня витрата
- Тарифи та коефіцієнти
- Користувачі та ролі
- Логи змін даних

### 3.4. Панель для стейкхолдерів
- Business Owner: KPI та бізнес-метрики
- Логіст: останні розрахунки та обрані параметри
- Бухгалтер: контроль правильності фінансових правил
- Розробник: технічні обмеження та стан інтеграції

## 4. Інтеграція з реальними базами
### Джерела даних
- База маршрутів: відстані, пункти завантаження/вивантаження, пункти пропуску
- База транспортних засобів: параметри пального, амортизації, вантажності
- База тарифів: середні витрати пального, комісії, адміністративні збори

### Механізми інтеграції
- API для отримання актуальних маршрутів та відстаней
- Синхронізація довідкових даних через ETL або доступ до бази даних
- Періодичне оновлення тарифів та параметрів автомобілів

## 5. Структура даних
### Об'єкти
- `Route`
  - `id`
  - `borderCheckpoint`
  - `loadingPoint`
  - `unloadingPoint`
  - `distanceKm`
  - `routeType`
- `Vehicle`
  - `id`
  - `name`
  - `fuelConsumptionLoaded`
  - `fuelConsumptionEmpty`
  - `amortizationPerKm`
  - `operationalCostPerKm`
- `CalculationParameters`
  - `fuelPrice`
  - `exchangeRate`
  - `precision`
  - `currency`
- `CalculationResult`
  - `totalCost`
  - `fuelCost`
  - `amortizationCost`
  - `operationalCost`
  - `distanceKm`
  - `runtimeMs`

## 6. Навігація
1. `Головний екран` → вибір маршруту та параметрів
2. `Результати` → перегляд та експорт
3. `Адмін` → управління довідковими даними
4. `Панель стейкхолдерів` → бізнес-метрики та статуси

## 7. Wireframe
### 7.1. Головний екран
| Компонент | Розташування | Опис |
|---|---|---|
| Пункт пропуску | зверху ліворуч | Список пунктів пропуску Україна–Польща |
| Маршрут завантаження/вивантаження | поруч | Два drop-down для вибору місць в Литві |
| Автомобіль | праворуч | Вибір транспортного засобу |
| Режим рейсу | нижче | Вибір: `на пусто` / `з вантажем` |
| Параметри пального | під формою | Введення ціни пального |
| Кнопка `Розрахувати` | внизу | Запуск розрахунку |

### 7.2. Екран результату
| Компонент | Розташування | Опис |
|---|---|---|
| Підсумкова сума | зверху | Великий результатний блок |
| Розбивка витрат | зліва | Таблиця з компонентами витрат |
| Інформація про маршрут | справа | Пункт пропуску, відстань, режим рейсу |
| Кнопки | внизу | `Експорт`, `Зберегти`, `Новий розрахунок` |

### 7.3. Адмін екран
| Компонент | Розташування | Опис |
|---|---|---|
| Меню | зліва | Посилання на `Маршрути`, `Транспорт`, `Тарифи`, `Користувачі` |
| Таблиця даних | центр | Список довідкових записів |
| Форма редагування | справа | Поля для додавання/редагування запису |
| Лог змін | знизу | Історія оновлень |

## 8. Сценарії використання
### Сценарій 1: Перший розрахунок
1. Логіст обирає пункт пропуску та маршрут.
2. Вибирає автомобіль і режим рейсу.
3. Вводить актуальну вартість пального.
4. Натискає `Розрахувати`.
5. Отримує собівартість та експортує результат.

### Сценарій 2: Оновлення довідкових даних
1. Адміністратор переходить в `Адмін`.
2. Оновлює параметри транспортного засобу та тарифи.
3. Зберігає зміни.
4. Система оновлює доступні варіанти для розрахунків.

## 9. Адміністративні функції
- Додавання/редагування пунктів пропуску
- Додавання/редагування маршрутів і відстаней
- Управління транспортом та витратами
- Оновлення тарифів пального та амортизації
- Контроль ролей користувачів
- Перегляд логів змін
